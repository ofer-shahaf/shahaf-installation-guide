# מסלול התקנה — שחף אלומיניום

כלי מעקב פרויקטים מהזמנה עד התקנה, בנוי מחדש מהקובץ הישן (`Excel/VBA`, ~2015)
ומותאם לעבודה מול קליל. אתר סטטי בלבד — HTML/CSS/JS רגילים, בלי שרת ובלי
שלב build. אפשר לפתוח את `index.html` ישירות בדפדפן, או לארח בחינם ב-GitHub Pages.

## מה יש בפנים

- **פרויקטים** — רשימת לקוחות עם 17 שלבי מסלול קבועים, סטטוס לכל שלב ותאריך יעד.
- **מנוע תאריכים אוטומטי** — מזינים תאריך לשלב אחד, והשלבים התלויים בו
  מחושבים לבד (בדיוק לפי הכללים שהיו בקוד ה-VBA המקורי). ראו מסך "כללי חישוב".
- **לוח שבועי** — כל המשימות המתוכננות של כל הלקוחות, לפי יום.
- **משימות היום** — מה צריך לקרות היום, בכל הפרויקטים.
- **חגים** — לוח חגי ישראל (מחושב ומאומת ל-2025–2033), עם אפשרות להוסיף/להסיר
  ימי חופש מותאמים אישית (חופשת מפעל וכו').
- **ייצוא/ייבוא** — כפתור לשמירת כל הנתונים לקובץ JSON ולטעינה חזרה. חשוב לגיבוי,
  כי הנתונים נשמרים רק בדפדפן המקומי (`localStorage`) — ראו הערת אזהרה למטה.

## ⚠️ הערה חשובה על שמירת נתונים

הנתונים (הפרויקטים, המשימות, התאריכים) נשמרים כרגע **רק בדפדפן שבו פותחים את
הדף**, לא בקבצי הפרויקט ולא בענן. זה אומר:
- פתיחת הדף ממחשב אחר / דפדפן אחר = התחלה מאפס.
- ניקוי היסטוריית הדפדפן עלול למחוק את הנתונים.

**מומלץ:** ללחוץ "ייצוא" מדי פעם (במיוחד אחרי עדכונים חשובים) ולשמור את קובץ
ה-JSON במקום בטוח (תיקייה משותפת, Drive וכו'). אם בעתיד תרצה שהנתונים יהיו
משותפים לכמה אנשים/מכשירים באופן אוטומטי — זה שלב נפרד (למשל גיליון Google
Sheets משותף, או בסיס נתונים קטן) ואפשר לבנות אותו בהמשך.

## הרצה מקומית

אין צורך בהתקנות. פשוט לפתוח את `index.html` בדפדפן (לחיצה כפולה על הקובץ,
או גרירה לחלון דפדפן פתוח).

לפיתוח נוח יותר (רענון אוטומטי) אפשר גם להריץ שרת סטטי פשוט:
```bash
cd shachaf-installation-tracker
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

## איך מעלים את זה ל-Git ואז ל-GitHub — מדריך צעד אחר צעד

ההנחה: יש לך כבר Git מותקן ו-GitHub CLI (`gh`) זמין (הם כבר מותקנים בסביבה הזו).
אם אתה עובד מהמחשב שלך ולא דרך הסביבה הזו, ההוראות זהות — רק תריץ אותן בטרמינל
של המחשב שלך בתוך תיקיית הפרויקט.

### שלב 1: יצירת ריפו Git מקומי

בתוך תיקיית `shachaf-installation-tracker`:

```bash
git init
git add .
git commit -m "גרסה ראשונה של מסלול התקנה"
```

### שלב 2: יצירת ריפו ב-GitHub

**אפשרות א׳ — עם GitHub CLI (הכי מהיר):**
```bash
gh auth login          # רק בפעם הראשונה, אם עוד לא מחובר
gh repo create shachaf-installation-tracker --private --source=. --remote=origin --push
```
זה יוצר ריפו **פרטי** ב-GitHub שלך, מחבר אותו לתיקייה המקומית, ומעלה (`push`)
את הקוד מיד. `--private` אומר שרק אתה (ומי שתזמין) יכולים לראות אותו.

**אפשרות ב׳ — דרך האתר:**
1. גולשים ל-github.com ולוחצים על "+" ← "New repository".
2. שם: `shachaf-installation-tracker` (או כל שם אחר).
3. בוחרים **Private**.
4. **לא** מסמנים "Add a README" (כבר יש לנו אחד).
5. לוחצים "Create repository".
6. GitHub יראה לך פקודות להרצה — הן דומות לזה:
```bash
git remote add origin https://github.com/<שם-המשתמש-שלך>/shachaf-installation-tracker.git
git branch -M main
git push -u origin main
```

### שלב 3: עדכונים עתידיים

בכל פעם שאני (או אתה) משנים קובץ ורוצים לשמור את זה ב-GitHub:
```bash
git add .
git commit -m "תיאור קצר של מה שהשתנה"
git push
```

### שלב 4 (רשות): פרסום כאתר חי עם GitHub Pages

אם תרצה קישור אינטרנטי לדף (למשל כדי לפתוח מכל מכשיר בלי להוריד קבצים):
1. בריפו ב-GitHub: **Settings → Pages**.
2. תחת "Source" בוחרים את הענף `main` ותיקייה `/ (root)`.
3. שומרים. אחרי דקה-שתיים GitHub ייתן לינק בסגנון:
   `https://<שם-המשתמש>.github.io/shachaf-installation-tracker/`

⚠️ שימו לב: גם עם ריפו **פרטי**, GitHub Pages דורש חשבון בתשלום (GitHub Pro/Team)
כדי להגיש עמוד שנשאר פרטי. בחשבון חינמי, הפעלת Pages על ריפו הופכת את *העמוד
המוגש* לציבורי גם אם הקוד המקורי בריפו פרטי — כדאי לבדוק זאת לפני הפעלה, או
להשאיר את הריפו כארכיון קוד בלבד ולפתוח את `index.html` מקומית / משרת פנימי.
